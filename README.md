# Погоняем лысого

Графический клиент для МАД «Сфера Миров» (sowmud.ru:5555): игра, карта, мобы, группа и профили персонажей в одном окне.
Неофициальный, не связан с администрацией игры. Алиасы и триггеры — в духе JMC, свои `.set` можно импортировать.

## Что нужно

- Windows 10 или 11
- [Python](https://www.python.org/downloads/) 3.10 или новее. При установке поставьте галочку **Add python.exe to PATH**
- Microsoft Edge (есть в Windows) или Google Chrome
- Больше ничего ставить не нужно: сторонние библиотеки не используются

## Установка и запуск

1. Скачайте `Pogonyaem-lysogo-X.Y.zip` со страницы [Releases](../../releases) и распакуйте в любую папку (не в «Program Files»).
2. Проверьте целостность по желанию: `КОНТРОЛЬНЫЕ_СУММЫ.txt` в архиве, а на странице релиза лежит `SHA256SUMS.txt` с суммой самого архива.
3. Дважды щёлкните **`Погоняем лысого.vbs`**. Откроется окно приложения.

Каждый запуск — новое окно. Хотите играть двумя персонажами — запустите дважды и выберите в окнах разные профили.

## Первый вход

1. В окне нажмите **«+ Новый профиль»**, введите имя персонажа и выберите:
   - **Чистый** — без алиасов и триггеров;
   - **Импорт из файла .set** — укажите файл JMC вашего персонажа (алиасы, триггеры, хоткеи, переменные, гаги). Сам `.set` не меняется.
     Если в нём есть триггеры входа («Введите имя своего пользователя», «Пароль:»), имя и пароль сохранятся для автологина.
2. Нажмите **«Подключиться»** (или **F12**). Имя аккаунта введётся само, если оно известно; если нет — введите его в строке ввода, клиент запомнит.
3. Когда игра попросит пароль, введите его в строке ввода. Поставьте галочку **«запомнить»**, чтобы дальше входить одной клавишей F12.

Сменить профиль — выпадающий список в шапке (если есть связь с игрой, клиент спросит и отключится).

## Что умеет

- Вывод игры со временем у каждой строки, гаги лишнего (`гаги.txt` + `#substitute` профиля), повторы схлопываются в «×N», галочка «скрытое» показывает загаганное, буфер прокрутки 20 000 строк.
- Алиасы и триггеры JMC (`#alias`, `#action`, `#variable`, `#group`, `#hot`). Править можно в **Опции → Алиасы и триггеры**; `#alias {..} {..}` и `#action {..} {..}` из строки ввода сразу пишутся в профиль. Триггеры включаются галочкой «триггеры работают».
- Карта зоны, миникарта, мобы на карте, карточки мобов, автоосмотр незнакомых, заметки к клеткам, поиск пути («Идти»), спидволки, окно группы.
- Окно **«Сообщения»**: клан, союз и группа в одном месте (строки группы с «!» — это команды, их там нет). Из окна игры эти сообщения убираются, если не стоит галочка «и в игре».
- Карта, которую игра печатает при `реж карт да`, показывается только в окне **«Миникарта»**, а не в окне игры. Кнопки движения — в отдельном окне **«Движение»** (кнопка ▦: крест, в строку, в столбец).
- Окна свободные: тащите за заголовок, меняйте размер за любой край или угол, **⟳** меняет ширину и высоту местами (горизонтальная ⇄ вертикальная ориентация), **✕** закрывает (вернуть — «Опции»). Раскладка запоминается и масштабируется вместе с окном; «Окна по умолчанию» возвращает исходную.
- Клик в любом месте окна ставит курсор в строку ввода. Esc: закрыть буфер прокрутки, затем очистить строку.

## Где что лежит

| Файл | Что это |
|---|---|
| `профиль_<имя>.txt` | алиасы, триггеры, хоткеи, переменные профиля (текст, формат как в `.set`) |
| `аккаунт_<имя>.txt` | строка 1 — имя аккаунта, строка 2 — пароль (если запомнили) |
| `game_<имя>.log` | полный лог игры, без цвета |
| `data\game.db` | база клеток и мобов; сюда же пишутся ваши заметки к клеткам |
| `data\ЗОНЫ\` | клетки зон, найденные эксплором |
| `гаги.txt` | регулярки строк, которые прячутся |

**Пароль хранится открытым текстом** в `аккаунт_<имя>.txt` на вашем компьютере. Не отдавайте этот файл и не выкладывайте его. Не хотите хранить — не ставьте галочку «запомнить».

## Обновление

Распакуйте новую версию **поверх** старой. Ваши `профиль_*.txt`, `аккаунт_*.txt` и логи в архиве не лежат, их не затронет. Заметки к клеткам хранятся в `data\game.db`: перед обновлением сохраните этот файл и верните его после распаковки (иначе заметки заменятся базой из релиза). Что изменилось — в [CHANGELOG.md](CHANGELOG.md).

## Если не запускается

- «Server did not start» — не установлен Python или он не в PATH. Откройте командную строку и выполните `python --version`.
- Окно не открывается — проверьте, что есть Edge или Chrome.
- «Профиль занят» — этот профиль уже открыт в другом окне приложения.
- Порт занят — клиент занимает первый свободный порт из 8765…8774.

## Для разработчиков

`server.py` — сервер (HTTP + SSE ⇄ telnet игры), `index.html` — интерфейс, `jmcprofile.py` — разбор синтаксиса JMC.
Запуск без лаунчера: `python -X utf8 server.py --port 8765`, затем http://localhost:8765.
Выпуск новой версии: `python выпуск.py` (подробности в начале файла).
